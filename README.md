# For Jeslyn ♡

A small birthday scrapbook made for Jeslyn, from Haffizol.

## Open locally

Open index.html in a browser, or serve this folder with any static web server. No build, package installation, or secrets required.

## What is inside

A personal letter, all seven supplied photos, an accessible photo viewer, a music corner with Spotify links, and a birthday candle surprise. Designed for phones and desktops with reduced motion support.

## Hosting

Publish the root folder using a static host, or configure GitHub Pages to use the main branch and / (root). Repository privacy is unchanged by this code. A hosted website can have a different audience from its source repository; choose hosting access deliberately.

Photos and the letter stay in the repository. Music links open Spotify; no music autoplays. Fonts use Google Fonts, with local system font fallbacks if unavailable.
